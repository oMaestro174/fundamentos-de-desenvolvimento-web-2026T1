# 📝 Avaliação A2: Layout Moderno com Flexbox, Grid e Design Responsivo
> **Disciplina:** Fundamentos de Desenvolvimento Web  
> **Carga Horária Equivalente:** Avaliação prática do Módulo de CSS3 e Responsividade (Aulas 04 e 05)  
> **Pontuação:** Vale a nota da segunda avaliação bimestral (**A2**).

---

## 🎯 Objetivo da Avaliação
Desenvolver uma página web completa de apresentação de uma startup, negócio local, catálogo ou portfólio, aplicando as técnicas de design moderno do CSS3, alinhamento com **Flexbox**, distribuição com **CSS Grid** e adaptação responsiva com **Media Queries** para celular, tablet e computador.

---

## 📋 Requisitos Obrigatórios da Entrega

### 1. Organização e Boas Práticas de CSS (Peso: 25%)
- [ ] Código CSS estruturado em arquivo externo (`style.css`).
- [ ] Uso do reset global com `box-sizing: border-box`.
- [ ] Paleta de cores harmônica e tipografia moderna importada (ex: Google Fonts).
- [ ] Variáveis CSS (`:root`) ou seletores organizados por componentes.

### 2. Alinhamento com Flexbox (Peso: 25%)
- [ ] Cabeçalho de navegação (Navbar) com logo e links alinhados via `display: flex`, `justify-content` e `align-items`.
- [ ] Botões com estados visuais `:hover` e `:active`.

### 3. Matriz com CSS Grid (Peso: 25%)
- [ ] Seção de conteúdo (produtos, serviços, depoimentos ou galeria) organizada via `display: grid`.
- [ ] Uso de espaçamento nativo via propriedade `gap`.
- [ ] Proporções fluidas utilizando frações (`1fr`).

### 4. Responsividade e Mobile-First (Peso: 25%)
- [ ] Meta tag `viewport` configurada no HTML.
- [ ] Uso de pelo menos duas Media Queries (`@media (max-width: 768px)` e `@media (max-width: 480px)`).
- [ ] **Zero overflow horizontal:** Em nenhuma resolução de tela a página deve apresentar barra de rolagem lateral indesejada.
- [ ] A interface deve ser 100% confortável para navegação por toque no smartphone.

---

## 🚀 Como Enviar a Avaliação
1. Desenvolva os arquivos `index.html` e `style.css`.
2. Teste em múltiplos tamanhos de tela pelo DevTools (`F12`).
3. Envie o arquivo compactado ou publique no seu repositório do GitHub conforme a orientação do professor.
