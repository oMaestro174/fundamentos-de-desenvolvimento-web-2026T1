# 🏆 Avaliação A3: Projeto Integrador Front-end Completo
> **Disciplina:** Fundamentos de Desenvolvimento Web  
> **Carga Horária Equivalente:** Avaliação final integradora (32 horas de curso)  
> **Pontuação:** Vale a nota final (**A3**) e a certificação da disciplina.

---

## 🎯 Objetivo da Avaliação
Desenvolver uma aplicação web front-end completa, funcional, moderna, semântica, totalmente responsiva e interativa que resolva um problema real para um cliente, empresa, ONG ou serviço público.

O projeto deve consolidar harmoniosamente os **três pilares** ensinados ao longo das 8 aulas:
1. **Estrutura:** HTML5 Semântico e Acessível.
2. **Apresentação:** CSS3 Moderno, Flexbox, CSS Grid e Design Responsivo (Mobile-First).
3. **Comportamento:** JavaScript nativo manipulando o DOM e reagindo a eventos de usuário.

---

## 📋 Matriz de Avaliação e Requisitos Técnicos

### 1. Estrutura HTML5 e Acessibilidade (Peso: 25%)
- [ ] Documento bem formado (`<!DOCTYPE html>`, `lang="pt-BR"`, `charset="UTF-8"`, `viewport`).
- [ ] Uso impecável de tags semânticas (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`).
- [ ] Formulário completo com validações nativas e 100% dos campos pareados com `<label for>`.
- [ ] Imagens otimizadas com atributo `alt` descritivo.

### 2. Estilização e Design Responsivo (Peso: 35%)
- [ ] Folha de estilo externa organizada (`style.css`) com reset universal `box-sizing: border-box`.
- [ ] Tipografia refinada via Google Fonts e paleta de cores harmônica.
- [ ] Uso efetivo de **Flexbox** para alinhamentos e barras de navegação.
- [ ] Uso efetivo de **CSS Grid** para distribuição de conteúdo em colunas/galerias.
- [ ] **Design Responsivo Total:** Adaptação fluida para Desktop, Tablet e Celular via Media Queries, com zero overflow lateral.

### 3. Dinamismo com JavaScript (Peso: 30%)
- [ ] Script externo (`script.js`) integrado sem erros no console.
- [ ] Pelo menos **duas funcionalidades interativas reais** desenvolvidas com manipulação do DOM e `addEventListener` (exemplos: menu mobile hambúrguer, tema claro/escuro, cálculo dinâmico, validação customizada, filtro de itens em tempo real ou carrinho/lista dinâmica).
- [ ] Código limpo com boas práticas de nomenclatura e uso de `const` e `let`.

### 4. Apresentação e Documentação (Peso: 10%)
- [ ] Arquivo `README.md` no projeto explicando o que o site faz, o público-alvo e como executá-lo.
- [ ] Código limpo, comentado e bem indentado.

---

## 🚀 Como Entregar
1. Crie uma pasta com a estrutura do projeto: `index.html`, `style.css`, `script.js` e pasta de imagens.
2. Envie o link do repositório no GitHub ou o arquivo compactado no portal acadêmico.
