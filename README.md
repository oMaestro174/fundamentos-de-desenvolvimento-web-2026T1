## 🚀 Visão Geral da Disciplina

Neste curso prático e imersivo, você aprenderá a construir páginas e aplicações web modernas do zero:
1. **HTML5 Semântico:** Estruturação correta da informação, tabelas, multimídia, formulários modernos e boas práticas de acessibilidade (WCAG).
2. **CSS3 Moderno:** Estilização com seletores avançados, variáveis CSS, Box Model, alinhamentos fluidos com **Flexbox** e **CSS Grid**, além de design responsivo **Mobile-First**.
3. **JavaScript Essencial & DOM:** Lógica de programação, variáveis modernas (`const`/`let`), manipulação dinâmica da árvore do navegador (DOM), escuta de eventos e persistência com `localStorage`.

## 🛠️ Ferramentas Necessárias

Antes do início das aulas, certifique-se de ter instalado em seu computador:
- **[Google Chrome](https://www.google.com/chrome/)** ou **[Mozilla Firefox](https://www.mozilla.org/pt-BR/firefox/)**: Navegador com DevTools integrado.
- **[Visual Studio Code](https://code.visualstudio.com/)**: Editor de código recomendado.
- **[Extensão Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)**: Para recarregamento automático no VS Code.
- **[Git](https://git-scm.com/)**: Controle de versão para clonar este repositório e realizar entregas.
